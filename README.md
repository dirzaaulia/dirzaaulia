### 🏛️ Architecture & Engineering Philosophy

Mobile and Multiplatform System Architect with **7+ years** of production engineering experience. Specializing in **Kotlin Multiplatform (CMP / KMP)**, **Jetpack Compose**, and **Compose for Web (Kotlin/Wasm)**, architecting cross-platform codebases that achieve near 100% logic and UI sharing without sacrificing native feel and high frame-rate performance.

- 🚀 **Kotlin-First & Multiplatform**: Architecting shared domain, data, networking, and UI layers across Android, WebAssembly, and iOS.
- ⚡ **High-Concurrency Telemetry**: Developing real-time sports telemetry pipelines, live match clips, and asynchronous data orchestration using Kotlin Coroutines & Flow.
- 📐 **Enterprise Scale**: Former core developer on **Alfagift**, Indonesia's premier omni-channel retail platform serving over 10 million active users.
